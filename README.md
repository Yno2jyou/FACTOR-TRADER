# FACTOR/TRADER

素数分解で株価が動くトレーディングゲーム。

## 遊び方

1. `index.html` をブラウザで開く（または GitHub Pages で公開）
2. LOCAL（vs CPU）または ONLINE（PeerJS）を選択

## ファビコン

ゲームアイコン（操作・妨害・防衛・反射）を白枠なしで使用しています。

## ファイル

- `index.html` / `factor_trader.html` — 本体
- `favicon.ico` / `favicon-16x16.png` / `favicon-32x32.png` — ファビコン
- `apple-touch-icon.png` — iOS ホーム画面用
- `icon-192.png` / `icon-512.png` — PWA 用
- `game-icon.png` — 元アイコン（白枠除去済み）
